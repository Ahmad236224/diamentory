# Brand assets drop folder

Place Diamentory's real files here; they will replace the illustrated placeholders.

- `logo/` — logo files (SVG preferred, plus PNG).
- `products/` — product photography, one folder per product (e.g. `products/cuban-link-chain/gold-1.jpg`). Square or 4:5 portrait, at least 2000px on the long edge, neutral background.
- `editorial/` — campaign/lookbook/lifestyle imagery for the homepage and lookbook.
- A catalogue spreadsheet (name, category, finishes, sizes/lengths, PKR price, stock, description, and — only if verified — materials, dimensions, care).
